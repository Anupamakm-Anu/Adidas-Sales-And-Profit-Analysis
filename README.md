# Adidas Sales and Profit Analysis Dashboard

## Project Overview
This project presents an interactive Adidas Sales and Profit Analysis Dashboard created using Microsoft Excel. The dashboard provides insights into sales performance, profitability, product categories, sales methods, and regional performance.

## Key Features
- KPI Metrics: Total Sales, Total Profit, and Total Units Sold.
- Category-wise Analysis: Sales and Profit by Product Category.
- Monthly Sales Trend: Tracks monthly sales performance.
- Sales Method Analysis: Compares Online, In-store, and Outlet sales.
- Regional Analysis: Analyzes sales across different regions.
- Retailer Analysis: Compares sales performance by retailer.
- Top Cities Analysis: Identifies top-performing cities by sales.
- Interactive Filters: Year, Product, and City slicers for dynamic analysis.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Visualizations
- Slicers
- Dashboard Design

## Project Objective
The objective of this project is to analyze Adidas sales data, identify sales trends, evaluate profitability, and understand product and regional performance through an interactive Excel dashboard.

## Conclusion
This dashboard helps users understand sales and profit trends, compare sales channels, and identify key areas of business performance using data visualization.
